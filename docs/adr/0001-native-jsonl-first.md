# 原生会话记录优先，扩展只补充必要缺失

Pi 原生 JSONL 是持久化系统状态、消息和工具声明的权威来源。Viewer 复用 Pi AI 的浏览器安全 transcript 工具沿分支重放，并由本地服务调用 Pi 原生上下文投影。离线导入不上传文件，不推断完整上下文投影。

扩展仅追加实际观测的 Harness 强制提示词与工具注册来源，使用明确的请求锚点及已持久化 Assistant ID 关联。观测独立于原生状态，不代表最终 Provider 请求。历史原始文件不改写；未知状态与明确空状态分别展示，不从当前配置推断历史。历史差异以同分支前一已知状态为基线。Vanilla 是独立的默认参考，由构建时安装的 Pi 原生提示词构建器生成并标明版本，不用于推断缺失的历史状态。

实现细节见 [原生 JSONL 分析](../design/native-jsonl-first.md)。
