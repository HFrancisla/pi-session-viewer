# 领域文档（Domain Docs）

本项目使用单一领域上下文，术语以仓库根目录的 `GLOSSARY.md` 为准。进行代码审查、实现或编写事项说明前，先读取该文件与相关源码，确保术语和业务规则来自当前实现。

## 文档位置

- `GLOSSARY.md`：会话、轮次、时间轴、提示词、上下文投影、子代理等中英文术语和当前验证约束。
- `docs/adr/`：仅在产生实际架构决策后存放相应 ADR。当前仓库没有已建立的 ADR，不将示例或未确认方案当成已决策内容。
- `README.zh-CN.md` 和 `README.md`：面向用户的当前安装、操作、安全边界和开发命令。

## 维护约束

修改领域术语时同时检查源码类型、测试和用户文档；`GLOSSARY.md` 的条目必须包含中文与英文代码映射。不要保留旧版本适配说明、未实施的计划或虚构的历史决策。如果已有 ADR 与当前代码出现冲突，应明确标注需要核实的差异，不能擅自把偏离行为确立为规则。
